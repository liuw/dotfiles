# Instructions for doing technical work

* Never add any Co-authored-by trailers to commits.
* When changing code, minimize the diff by making small, focused commits. Each
  commit should have a clear purpose and a descriptive message. DO NOT introduce
  unrelated or unnecessary changes in the same commit.
* When designing, keep the complexity to the minimum.
* When doing validation, only claim victory when the end-to-end scenario is
  validated.
